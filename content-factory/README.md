# Content Factory — RU Clips

Автоматический бесплатный конвейер для подготовки вертикальных роликов из публичных официальных промо-материалов российских фильмов, сериалов и шоу.

## Источники

- RUTUBE — основной источник.
- VK Видео — дополнительный источник; приватные, подписочные и требующие авторизации ролики пропускаются.
- Только публичные ссылки официальных правообладателей/каналов или материалы, на использование которых есть разрешение.

## Что делает pipeline

1. Принимает URL публичного видео.
2. Проверяет домен и не использует cookies/авторизацию.
3. Загружает доступный публичный файл через yt-dlp.
4. Создаёт вертикальный 1080x1920 ролик через FFmpeg.
5. Нарезает выбранные интервалы, склеивает их и ограничивает итоговую длину.
6. Сохраняет MP4 как GitHub Actions artifact.

## Запуск

Workflow: `.github/workflows/content-factory-ru.yml`.

Параметры ручного запуска:

- `source_url` — публичная ссылка RUTUBE/VK.
- `segments` — интервалы в секундах, например `0-5,12-18,31-38`.
- `title` — короткое имя ролика.

Если интервалы не заданы, pipeline берёт первые 45 секунд доступного видео и делает черновик.

## Ограничения

Pipeline не обходит DRM, логины, платные подписки, геоблоки или ограничения доступа. Если видео нельзя получить публично, задача завершается без попыток обхода.
