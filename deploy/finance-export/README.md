## Текущий шаг: проверка совместимости

`check.py` — самостоятельный Python-скрипт. Он читает Docker metadata, хеши
текущих файлов и названия колонок четырёх таблиц через `information_schema`
в транзакции `READ ONLY` с ограничением времени SQL 3 секунды. Строки заявок,
сотрудников и расходов не читаются. Конфигурационные секреты обрабатываются
только в памяти при определении реального маршрута Edge → REST → DB;
значения env, URI с паролями, исходный код и тела ошибок не выводятся.

Скрипт ничего не устанавливает, не изменяет production-файлы/БД и не
перезапускает контейнеры. `CHECK_COMPLETE=true` означает только завершение
диагностики, а не готовность установки или публикацию. Различия в модулях и
отсутствующие колонки требуют разбора перед подготовкой кандидата.

`prepare-check.py` воспроизводит встроенные эталонные хеши из родителя
проверенного commit и список колонок из его реальных API projections.
Runtime-код активных bundle имеет приоритет над оставшимися standalone-копиями.
Для сравнения нормализуются только три известные базовые URL; остальные
изменения не игнорируются.

Проверки: `python3 -m unittest discover -s deploy/finance-export -p 'test_check.py' -v`.
Одиннадцать тестов проверяют отсутствие изменений файлов, метаданные вместо чтения
клиентских строк, отсутствие секретов в выводе/psql arguments, ограничение
маршрута БД общей Docker-сетью, отказ при вложенных mounts и symlink/path escape.

Компилированная eszip проверяется потоково по 64 KiB, отдельно от ограничения
исходников 4 MB, с пределом 128 MiB. Отсутствующий файл, symlink, превышение
лимита и изменение во время чтения имеют отдельные коды. Ошибка этой независимой
проверки не мешает вывести результаты проверки колонок; она не означает допуск
к установке. На первом запуске пользователь подтвердил совпадение API baseline,
целостность manifest и единственное отличие web — действующий RU-router.

Финансовый endpoint требует обновления существующего `mini-app-api` и его eszip;
одна замена frontend недостаточна. Generic-сборка из Git не должна заменять
RU-router, актуальные адреса и несвязанные исправления отчётов. Установщик,
резервная копия, компиляция/проверка кандидата и откат будут привязаны к
подтверждённой текущей версии. На этом шаге они ещё не выполнены.
