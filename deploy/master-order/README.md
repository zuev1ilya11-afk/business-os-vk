Пакет `bos300.pyz` изменяет только интерфейс. Он сохраняет действующие российские
маршруты API, все прочие модули и более новую серверную версию редактора подсказок.
В последней меняется только размещение кнопки помощи внутри карточки.
Backend, исправление дат Лемана, БД, выплаты, настройки и секреты не изменяются.
Заявки и отчёты для проверки на сервере не создаются и не редактируются.

## Запуск

После скачивания закреплённого пакета в `/root/bos300.pyz`:

```sh
python3 /root/bos300.pyz --check
python3 /root/bos300.pyz --apply
```

`--check` только читает: проверяет исходные файлы, необязательные исходники,
контейнер Caddy, HTTPS и свободное место. При другой исходной версии останавливается.
Пакет не отключает проверку TLS-сертификата.

`--apply` сохраняет полную проверенную копию web-каталога, готовит новую копию,
проверяет неизменность всех прочих файлов и прав, атомарно меняет каталоги и
перезапускает только существующий Caddy. Затем проверяет все ожидаемые публичные
файлы по HTTPS. При сбое активации восстанавливает прежний интерфейс.
Во время перезапуска возможно краткое прерывание доступа.

Только строка `RELEASE_OK BUILD_ID=b44db0b2084a5c0cc743` подтверждает успешную
установку. Повторный запуск проверяет установленную версию и выдаёт `ALREADY_DEPLOYED`.
Резервная копия и журнал: `/opt/business-os/deploy/master-order-300-web`.

Откат:

```sh
python3 /root/bos300.pyz --rollback
```

Откат возвращает только предыдущий интерфейс. Более поздние изменения файлов или
конфигурации контейнера блокируют откат. После прерывания активации сначала выполнить
откат; повторная установка сохраняет предыдущие попытки в каталогах `*-history-*`.
Не удалять резервные копии и не запускать более старые установщики поверх этого выпуска.

После установки обновить приложение на телефоне и открыть существующую заявку мастера:
визит, следующая кнопка, звонок, работы, выплата, «Дополнительно». Физический iPhone/Safari
не проверялся автоматически.

## Проверки и воспроизведение

- PR300: GitHub job `119888353346` — все обязательные этапы успешны, включая TypeScript,
  PostgreSQL и полный UI; 867 UI прошли сразу, один прошёл при повторе, 6 пропущены.
- Установщик: 16 тестов с настоящими временными файлами и атомарным обменом каталогов;
  Docker и HTTPS заменены явными тестовыми адаптерами. Проверены сбои перезапуска/HTTPS,
  прерывание, повторная установка, сохранность файлов, прав и отказ при более новых изменениях.
- Независимое ревью: блокирующих замечаний нет. Все 59 runtime-ресурсов, HTML, SW и manifest
  согласованы; изменены ровно 4 из 107 модулей startup bundle и 2 отдельных файла.
- Серверная сборка: 32 UI-теста прошли после адаптации фикстуры; использованы синтетические данные. Фикстура перехватывает
  также HTTP localhost, куда сохранённый RU adapter перенаправляет старые API-адреса;
  первый прогон без этой адаптации дал 31 успех и один HTTP501 от локального file server.
  Реальная серверная API-логика этим прогоном не проверяется.
- Фактический запуск на сервере и проверка HTTPS остаются этапом установки пользователя;
  подготовка архива сама по себе не означает публикацию.
