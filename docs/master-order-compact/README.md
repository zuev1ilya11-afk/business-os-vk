# Компактная карточка заявки мастера

Реализовано в существующем интерфейсе Business OS по утверждённому макету. База ветки: `origin/main`, `1ff029deaaa08d2d0181fea1826f912b47b19280`. Работа ведётся отдельно от прежних рабочих папок. Production не обновлялся, слияние в main не выполнялось.

## Что изменилось

- Номер, фактический статус и закрытие — компактная шапка. Дата поступления и помощь находятся в «Дополнительно».
- Один блок даты, времени, адреса и уточнений. Ссылка на Яндекс Карты сохранена. Сегодня/Завтра считаются по Москве; отсутствующие дата, время и адрес явно обозначены. Изменение визита при обновлении данных отражается в уже открытой карточке.
- Четыре этапа: Назначена → Выезд → Работа → Отчёт. Одна основная кнопка и две вторичных. Используются прежние обработчики и подтверждения. Ручное завершение не изображает неподтверждённые этапы выполненными.
- Клиент, телефон, копирование и звонок видны сразу. Сводка контакта не повторяет телефон и время визита; длинный комментарий и история раскрываются.
- Структурированные работы отображаются с исходными количествами и единицами. Свободное описание вынесено отдельно; пустой work_items не превращает текст в позиции. У прежних заявок без work_items сохранён существующий список строк. Числа из примечаний не используются как количества.
- Выплата отображается по существующим правилам. Ноль отличается от отсутствующего значения; amount_confirmed=false показывает «Не рассчитана». БД, API и расчёт зарплаты не менялись.
- Сохранены просмотр отчёта, акты, фотографии, помощь, согласование переноса. Единственная область прокрутки карточки; основное действие находится в потоке содержимого.

## Фактические проверки

| Проверка | Результат |
| --- | --- |
| `npm run build`, `npm run build:check` | Успешно, build `7d049172dab1f840bdd0` |
| Серверный набор `node --test tests/*.test.cjs` | 787 прошли, 0 ошибок |
| Полный UI-набор в режиме запрета внешних запросов | 872 сценария: 858 прошли, 4 пропущены, 10 потребовали повторной проверки |
| Повторная проверка затронутых UI-файлов | 48 прошли; затем 3 мобильных сценария прошли после уточнения селектора подписи в карточке, список заявок сохранил прежнюю подпись |
| Акты и фотографии | Все 6 сценариев повторного прогона прошли |
| Результат полного набора с учётом повторных прогонов | 868 сценариев прошли, 4 пропущены; известных оставшихся падений нет |
| Целевые сценарии карточки/переходов/ошибок/ролей | 62 прошли; дополнительно проверены обновление открытого визита и ручное завершение без отметок этапов |
| Локальное превью | Проверены помощь, запрос переноса без самостоятельного изменения даты и подтверждение выезда; скриншоты 360/390/430/1440 px |
| `git diff --check` | Успешно |

Причины 10 падений полного первого UI-прогона: девять ожидали прежние подписи/размещение (время в результате контакта, старый текст выплаты/этапа, постоянно раскрытые фотографии и прежний контейнер переноса). Один тест управления заявкой проверял асинхронное сохранение комментария немедленно; ожидание результата уточнено, бизнес-код формы не менялся. Все десять повторно прошли. Проверки внешних рабочих GAS-сервисов исключены существующей offline-конфигурацией; реальные клиенты, сотрудники и production-заявки не использовались.

Safari/WebKit и физический iPhone не проверены: WebKit загружен, но системные библиотеки отсутствуют, установка зависимостей ограничена средой. Мобильные размеры и существующие PWA-сценарии проверены Chromium; это не замена испытанию на устройстве. Полный серверный CI с Deno и отдельным PostgreSQL выполняется по правилам репозитория, локально здесь запускался Node-набор.

## Реальное локальное превью

Из этой ветки после установки зависимостей:

```bash
npm run preview:master-order
```

Открыть `http://127.0.0.1:4176/` на компьютере, где запущена команда. Это настоящий index.html и его собранные модули с существующими тестовыми Edge-обработчиками. Все данные вымышлены, изменения живут только в памяти, внешние звонки/ссылки и обращения к production не выполняются. Отдельная демонстрационная страница не создавалась. Внешняя ссылка на опубликованное превью не создана.

Повторить проверку и скриншоты:

```bash
npm run test:preview-master-order
```
