## 2. Среда и проверка

Node.js 24.22.1, npm 11.9.0, установка по lockfile через `npm ci`. Обработчики исполнялись с синтетическими БД/Storage/Drive и запретом неожиданных fetch; выбранные SQL-контракты — в PGlite. Браузер: закреплённый Playwright Chromium Headless Shell, локальный сервер, deny-external proxy; прямые GAS health-запросы исключены. Системный Chromium не запускался из-за запрета singleton socket; закреплённый headless shell работает. Физические телефоны и реальные внешние доставки не проверены.

Итоговые числа и ограничения: [VERIFICATION.json](audit/VERIFICATION.json). Базовый серверный набор — 860/860. Целевые группы пересекаются, их числа не суммируются. Сборщик серверных метаданных проверен 8 тестами. Успешная сборка не заменяет проверку бизнес-сценариев.

После исправлений: **916/916 серверных**. Последний полный локальный UI-прогон с диагностикой: **890 прошли, 0 ошибок, 4 пропуска**, 8,9 минуты; включает повтор создания после потери ответа. Deno 2.9.7 для **7 API** прошёл с локально подготовленными зависимостями. Два GAS health-файла исключены отдельно; четыре пропуска относятся к необязательной генерации иллюстраций.

История проверки сохранена: базовый UI — 889/0/4; первый полный повтор после исправлений — **888 прошли, 1 ошибка, 4 пропуска**. Очистка комментария владельцем один раз не сохранилась. Точный повтор 10/10, файл 33/33 и последний полный прогон проходят; причина исходного сбоя не установлена и исправление не заявляется. Проверки не ослаблялись; AUD-15 остаётся риском для проверки на соответствующем серверу стенде. [Обезличенное свидетельство сбоя](audit/UI_INTERMITTENT_FAILURE.json) сохранено вместе с отчётом.

Финальный код: remote [`a243741efd86f1148732d2c843c9d3ba48bca459`](https://github.com/zuev1ilya11-afk/business-os-vk/commit/a243741efd86f1148732d2c843c9d3ba48bca459), локальный `8fb2bb518b4fc34c1676f1eb0d7b9659a905f920`; дерево идентично: `5fcb35724286712a74614eb942992317962c6a9d`. Различаются SHA коммитов из-за способа публикации, не содержимое файлов. Последующее обновление отчёта меняет только документацию. [GitHub run 43071557158](https://github.com/zuev1ilya11-afk/business-os-vk/actions/runs/43071557158) **завершился успешно**: 916 серверных, 890 UI, 0 ошибок, 6 ожидаемых UI-пропусков (2 live GAS + 4 capture-only). Проверены типизация 10 API, frozen push/Avito/Hands, 8 SQL-наборов на отдельном PostgreSQL 17.6 (включая конкурентный импорт), сборщик и серверные регрессии.
