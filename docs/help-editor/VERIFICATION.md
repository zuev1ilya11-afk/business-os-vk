## Что реализовано

Профиль владельца/руководителя → «Подсказки по работе» → «Управление подсказками». В выбранном разделе доступны «Добавить подсказку» и «Редактировать» у материала. Форма сохраняет через тот же серверный API, который отдаёт содержание мастеру. Все четыре вида материала охвачены; новые шаги могут быть без изображения. Существующие изображения и учебные варианты не редактируются и сохраняются по ID.

Удалены именно две FAQ-записи с полным содержимым. Автоматическое сравнение с базовым коммитом подтверждает неизменность остальных полей, включая гарантию 1 год. Добавлены постоянные ID материалов и шагов.

Подготовлено общее хранение: отдельная таблица master_help_materials для существующей RU PostgreSQL. Миграция на RU ещё не применялась. Расширены только операции master-memo-api; механизм проверки подписанного сеанса/активного сотрудника сохранён. Локальный кэш используется только для чтения, никогда как подтверждение записи. Доступ на запись задаётся сервером по owner/manager.

## Фактически проверено

- Node: роли owner/manager создают и правят; master/dispatcher/admin получают 403, включая подставленные role/preview_role/actor. Нет, истёкший или неактивный сеанс отклоняется.
- Node: повтор отправки не дублирует карточку/версию; параллельная запись даёт один успех и один 409; обязательные поля/категории проверяются; изображения/учебные варианты защищены.
- Сравнение контента: все остальные тексты/иллюстрации/ветвления сохранены точно; уникальные постоянные ID.
- PGlite (реальный PostgreSQL WASM): schema/seed повторяемы, правки сохранены, оба удалённых вопроса отсутствуют; anon/authenticated не могут читать/писать таблицу напрямую. API с подписанными тестовыми сеансами работает с SQL-базой, данные сохраняются после закрытия и повторного открытия базы с диска.
- Playwright Chromium: вход из собственных профилей owner/manager, редактирование всех четырёх типов, добавление шага, видимость новой подсказки у мастера после повторного открытия и перезагрузки. Ошибка сети сохраняет текст; сохранение блокирует повторное нажатие; конфликт не стирает черновик; HTML показывается как текст.
- Playwright Chromium: чистая отмена не предупреждает; Escape/Back с грязной формой предупреждают; отказ оставляет текст. Кэш читается без сети, управление недоступно. Запоздалый ответ старого открытия не заменяет свежую версию.
- Мобильный viewport: редактор прокручивается, simulated visualViewport при клавиатуре уменьшает диалог до доступной высоты, нижние кнопки достижимы. Existing help tests проверяют уроки/картинки/копирование/поиск/категории и сохранность основных форм на 320/390/768/1440 px.
- Отдельная HTTP-демонстрация: create/edit, полный перезапуск сервера и базы, чтение мастером, прямой запрос мастера → 403. См. preview-check.json.
