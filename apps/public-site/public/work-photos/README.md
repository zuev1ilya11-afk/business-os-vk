# Изображения для сайта

Локальные иллюстративные WebP-изображения, подготовленные из сгенерированных дизайн-макетов. Они не являются подтверждёнными фотографиями реальных заказов компании. В галерее это прямо указано. При появлении собственных фотографий с разрешением на публикацию замените соответствующие файлы с сохранением имён; тогда обновите подпись галереи и описания по фактическим работам.
