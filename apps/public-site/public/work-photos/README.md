# Изображения для сайта

Локальные иллюстративные WebP-изображения, подготовленные из сгенерированных дизайн-макетов. Они не являются подтверждёнными фотографиями реальных заказов компании. В галерее это прямо указано. При появлении собственных фотографий с разрешением на публикацию замените соответствующие файлы с сохранением имён; тогда обновите подпись галереи и описания по фактическим работам.

Премиальная редакция: hero-premium.webp (1672 × 941) — самостоятельная сгенерированная интерьерная иллюстрация; hero-mobile.webp (800 × 759) — адаптивная версия без увеличения исходника. Изображения facade-premium.webp и facade-*.webp — иллюстративные фрагменты архитектурного дизайн-макета. Они не подтверждают выполнение работ компанией. Исходные изображения бытовых услуг остаются локальными; заменяйте их реальными фото с разрешением на публикацию или самостоятельными изображениями достаточного разрешения.
